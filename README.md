# 2023 年全国大学生数学建模竞赛 C 题

## 商超生鲜蔬菜补货与动态定价

**成果：全国大学生数学建模竞赛浙江省一等奖**  
**角色：队长、建模手**

本项目面向生鲜蔬菜易损耗、需求波动和有限陈列空间下的日常经营决策，使用近三年商超销售与批发价格数据，分析品类和单品之间的关系，并将预测结果用于补货与定价优化。

## 项目工作

- **数据整理与探索**：处理约 82 万条销售流水，关联商品、品类、批发价格和损耗率信息；进行缺失值补齐、异常记录筛查和日期粒度汇总。
- **需求关系分析**：使用描述性统计、灰色关联分析和 Spearman 相关分析，识别品类销量的季节性、工作日与休息日差异，以及单品间的互补/替代关系。
- **销量与价格预测**：对品类销量使用 ARIMA 等时间序列方法；在单品小样本场景使用 GM(1,1) 灰色预测，并拟合价格—需求关系，为优化模型提供输入和边界。
- **品类级经营优化**：以商超收益最大化为目标，综合需求、进价、成本加成和损耗等因素，求解未来一周的品类补货与定价方案。
- **单品级组合优化**：针对 49 个候选单品，引入 0-1 选择变量、27–33 个单品数量约束、最小陈列量与需求满足惩罚，构建非线性混合整数优化模型，并以遗传算法求解。论文示例选择 33 个单品；收敛曲线约在 160 代后趋稳。
- **稳健性检查**：对预测批发价进行 ±5% 扰动，比较优化策略变化；并检查遗传算法迭代收敛情况。

## 可直接放入简历的表述

**商超生鲜补货与动态定价优化｜2023 年全国大学生数学建模竞赛浙江省一等奖**  
担任队长兼建模手，基于约 82 万条、覆盖近三年的生鲜销售流水，完成数据清洗、缺失补齐及异常记录筛查；结合灰色关联与 Spearman 分析识别品类时序规律及单品互补/替代关系，使用 ARIMA、GM(1,1) 预测销量与批发价；进一步构建纳入损耗、需求和陈列约束的非线性混合整数优化模型，以遗传算法求解品类及单品补货、定价策略，并通过进价 ±5% 扰动开展敏感性分析。

## 复现说明

代码目录保留竞赛阶段的原始 Python 脚本。脚本依赖竞赛数据表及运行过程中生成的中间文件，且部分文件名和工作目录按当时本地环境设置；当前仓库没有包含原始销售数据，因此暂不保证克隆后可直接一键运行。论文与脚本用于展示建模过程，复现实验需按脚本读取的表名准备数据，并核对文件路径、列名和编码。

主要使用 Python、Pandas、NumPy、SciPy、statsmodels、scikit-learn、Matplotlib、Seaborn 与 DEAP。

## 结果口径

补货、价格及收益相关输出是基于题目数据和模型假设得到的竞赛方案，不代表商超实际执行结果或已实现经营增益。相关性用于发现候选关系，不作因果解释。
